# 项目背景
  现在打工人，上班过于沉迷，沉迷于老板的命令，沉迷于同事的坚持，沉迷于自身的苦不堪言，沉迷于外界的种种压力。到底是心流还是职业倦怠？我们习惯了被告知什么是好，什么是坏。是时候问一下自身了。
  如何脱离这种状态，需要的就是重新意识到时间，意识到自己的情绪。
  如何意识到情绪呢？需要一个工具来采集你的数据，你的每一次呼吸，震动，键盘的敲击，鼠标的点击，这些都是办公室打工人的大多数时间。
  当我们意识到情绪后，也就可以释放出时间，从而拥有自己的时间。

# 项目介绍
一个基于高性能全栈技术的、非侵入式心理状态调控生态。它通过感知人类微弱的生理电信号，利用环境暗示取代弹窗提醒，旨在消除职业倦怠，重建个体与工作环境的数字边界。

## 解题思路
**数据** 来源于电脑和生物信号，通过非侵入方式获取数据，包含：震动、呼吸、键盘、鼠标。通过数据分析，来识别用户的情绪状态，进而通过心理学的暗示来调控用户的情绪状态。

**心理学** 颜色和声音是两大利器，不需要太多的信息，营造一种潜意识感知的氛围即可。蓝色代表忧郁，红色代表愤怒，绿色代表平静。高亮代表工作，暗淡代表休息。声音方面，通过和弦来营造一种氛围，和弦的变化代表情绪的变化。

**技术展** 电脑端考虑Windows和Mac的系统（Ubuntu暂时搁置），通过Flutter来实现界面的美化，也方便手机APP端的开发。数据采集方面通过C语言，高性能采集电脑数据，生物信号通过低功耗嵌入式设备来获取（毫米波，震动）。基于网络联网来实现采集数据的上报，减少客户端的压力，客户端数据没有明显关联，只作为数据。云端生成报告以便客户端获取。

# 未来考虑

    2. 个性化调控：根据用户的情绪状态，提供个性化的调控建议和方案。
